TVM cheat sheet

Time value of money

Future value

FV = PV × (1 + r)^n

Present value

PV = FV / (1 + r)^n

Annuity (PV)

PV = C × [1 − (1 + r)^−n] / r

Perpetuity

PV = C / r

Tip: match r and n to the same period (monthly rate with months).
